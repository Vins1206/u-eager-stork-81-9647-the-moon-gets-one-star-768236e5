A make.fun entry for **The Moon Gets One Star** ($2): the funniest one-star review of the Moon in 120 characters or fewer.

## The entry

> One star. It follows me everywhere, pays no rent, and vanishes once a month without a word.

91 characters. A petty, real-review grievance that could only be about the Moon: it follows you everywhere, and once a month (the new moon) it just vanishes.

## How to run

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (pure Python standard library, no network, no input).
